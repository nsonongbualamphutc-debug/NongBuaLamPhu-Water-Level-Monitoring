🔐 Sub-Admin คืออะไร? Sub-Admin คือผู้ดูแล "ระดับกลาง" ที่กรอกข้อมูล ข้ามทุกจุดในประเภทของตน แต่ ไม่สามารถจัดการ PIN ของเจ้าหน้าที่จุดอื่น
ตัวอย่างการใช้งาน: เจ้าหน้าที่ปกครองอำเภอที่ดูแลฝนทุกอำเภอ / เจ้าหน้าที่ลำน้ำที่ดูแลสถานีหลายแห่ง
⚙️ การตั้งค่า Sub-Admin PIN
Sub-Admin PIN ตั้งค่าผ่าน Apps Script → Project Settings → Script Properties เท่านั้น (เพื่อความปลอดภัย ไม่จัดเก็บใน Sheet)
สร้าง 3 keys ตามต้องการ:
💧 Water Admin
กรอกระดับน้ำได้ทุกสถานี (20 สถานี · 4 ลำน้ำ)
Key: WATER_ADMIN_PIN
🌧️ Rain Admin
กรอกฝนได้ทุกอำเภอ (6 อำเภอ)
Key: RAIN_ADMIN_PIN
🏞️ Reservoir Admin
กรอกอ่างเก็บน้ำได้ทุกอ่าง (15 อ่าง)
Key: RESERVOIR_ADMIN_PIN
วิธีตั้งค่า:
1. เปิด script.google.com → โปรเจคของระบบ
2. ⚙️ Project Settings (ฟันเฟือง มุมซ้าย)
3. เลื่อนลง "Script Properties" → กด "Add script property"
4. ใส่ Key ตามด้านบน · Value = PIN ที่ต้องการ (ตัวอักษร/ตัวเลข ≥6 ตัว)
5. กด "Save script properties" — เสร็จแล้วใช้ได้ทันที (ไม่ต้อง redeploy)
⚠️ ความปลอดภัย: Sub-Admin PIN ควรยาว ≥6 ตัวอักษร และไม่ควรง่ายต่อการเดา · ห้ามแชร์กับผู้ที่ไม่ได้รับมอบหมาย

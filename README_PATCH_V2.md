# PATCH v2 — "เปิดมาเจอคำตอบ ไม่ใช่ข้อมูล"
ระบบติดตามสถานการณ์น้ำ จ.หนองบัวลำภู · มิถุนายน 2569

## Patch นี้ทำอะไร

เพิ่มส่วน **"คำตัดสินสถานการณ์" (Verdict)** ด้านบนของแดชบอร์ดทั้ง 6 หน้า
โดย**ไม่แก้โค้ดเดิมแม้แต่ฟังก์ชันเดียว** (ใช้วิธี wrap render ของหน้านั้น)
และ**ไม่แตะ input.html / ระบบกรอกข้อมูล** ใด ๆ ทั้งสิ้น

| หน้า | สิ่งที่ได้ |
|---|---|
| index.html | Hero คำตัดสินทั้งจังหวัด + มาตรตลิ่ง + จับตาวันนี้ Top 3 + เช็คพื้นที่รายอำเภอ + ปุ่มคัดลอกรายงานเช้า |
| paneang / mong / mo / phuay | แถบสรุปย่อรายลำน้ำ + มาตรตลิ่งของลำน้ำนั้น + ปุ่มคัดลอกรายงาน |
| reservoir.html | แถบสรุป % เก็บกัก + อ่างที่ % สูงสุด + ปุ่มคัดลอกรายงาน |

ทุกอย่างคำนวณจากข้อมูลจริงที่หน้านั้นโหลดอยู่แล้ว (API เดิม ไม่ต้องแก้ Code.gs เพิ่ม)

## ไฟล์ในชุดนี้

**ไฟล์ใหม่ (2):**
- `verdict.css` — สไตล์คอมโพเนนต์ (รองรับ dark mode + print)
- `verdict.js` — ตรรกะวิเคราะห์ + วาด + สร้างข้อความรายงาน

**ไฟล์ที่ patch แล้ว (6):** index, paneang, mong, mo, phuay, reservoir
แต่ละไฟล์ถูกเพิ่มแค่ 3 บรรทัด:
1. `<link rel="stylesheet" href="verdict.css">` ใน head
2. `<div id="verdictZone" data-vd="...">` หลัง nav
3. `<script src="verdict.js"></script>` ก่อนปิด body

**หมายเหตุ:** ไฟล์ชุดนี้รวมงานรอบก่อนแล้ว (Service Worker + manifest)
และ sw.js ขยับเป็น `wnb-v2` พร้อม precache verdict.css/js แล้ว

## วิธีติดตั้ง

อัปโหลดทุกไฟล์ขึ้น GitHub Pages ทับของเดิม + เพิ่ม verdict.css, verdict.js
(Code.gs ใช้เวอร์ชันจากรอบ LockService — ถ้ายังไม่ deploy ให้ deploy ด้วย)

## วิธีถอด Patch (rollback)

ทำได้ 2 ระดับ:
1. **ปิดเฉพาะหน้า:** ลบ 3 บรรทัดที่เพิ่ม (หาคำว่า `PATCH v2` ในไฟล์)
2. **ปิดทั้งระบบ:** ลบไฟล์ `verdict.js` ออกจากเซิร์ฟเวอร์ — ทุกหน้ากลับเป็นเหมือนเดิมทันที
   (div ว่างไม่มีผลต่อหน้าตา)

อย่าลืมขยับ VERSION ใน sw.js ทุกครั้งที่แก้ไฟล์ เพื่อล้าง cache ผู้ใช้

## เกณฑ์ที่ใช้ตัดสิน

- ระดับสถานการณ์รวม: มีสถานีวิกฤติ ≥1 → วิกฤติ / เฝ้าระวัง ≥1 → เฝ้าระวัง / นอกนั้น ปกติ
- มาตรตลิ่ง: สถานีที่ (ระดับตลิ่ง − ระดับปัจจุบัน) น้อยที่สุด
- การ์ดฝนหนัก: โผล่เมื่อฝนสูงสุด ≥35 มม./24 ชม. (สีแดงเมื่อ ≥90)
- สถานะอำเภอ: แย่สุดของสถานีในอำเภอนั้น + ยกเป็นเฝ้าระวังเมื่อฝน ≥90 มม.
- อ่างเก็บน้ำ: เฝ้าระวังเมื่อเก็บกัก ≥80% / วิกฤติเมื่อ ≥100%

เกณฑ์เหล่านี้แก้ได้ที่ต้นไฟล์ verdict.js
